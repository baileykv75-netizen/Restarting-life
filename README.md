# Restarting Life

**《此世问长生》**：纯文字、规则驱动、不接入大模型 API 的修仙人生 Roguelike。

V1 设计与技术边界以 [`GAME_DESIGN_V1.md`](./GAME_DESIGN_V1.md) 为核心基线。V1 不制作童年交互事件，因此出生信息生成后，玩家从 **16 岁**开始做第一项人生选择。

## 当前阶段

**阶段 7：V1 可玩界面**

阶段 0～6 已通过 GitHub Actions。阶段 7 只把既有引擎、正式事件、存档和前世档案接到网页界面，不新增核心玩法。

## V1 闭环

```text
随机出身 / 灵根 / 两个天赋
→ 16 岁进入可操作人生
→ 凡尘谋生 / 寻找仙缘
→ 青云宗或散修
→ 引气入体
→ 炼气 1～9 层
→ 筑基前 / 中 / 后期
→ 结丹
→ 金丹通关或寿元耗尽
→ 人生总结
→ 前世档案
→ 再入轮回
```

正式内容现有 30 个普通事件、10 个奇遇、5 条三节点长期因果链和 3 个大境界突破事件，共 53 个正式事件。阶段 3 的 8 个 `test_` 事件只做回归测试。

## 玩家界面

网页端提供：开启第一世 / 再入轮回；角色状态；中央文字事件卡与条件选项；四类行动；此世纪年；终局人生总结；前世档案；本地继续游戏；桌面与手机响应式布局。

UI 不直接修改 `GameState`。操作统一经过：

```text
React UI
→ persistentGameEngine
→ sessionEngine
→ action / event / breakthrough engine
→ 得到完整状态
→ 保存 PersistentGame
→ React 更新显示
```

## 四类行动

- **闭关修炼**：1 年，基础修为结算后可能触发修炼事件；
- **外出历练**：半年，进入历练、奇遇和长期因果内容；
- **凡尘谋生 / 接取委托 / 宗门任务**：半年，根据身份进入对应事件池；
- **尝试突破**：进入专属突破事件，再由规则引擎判定结果。

事件处理中普通行动会锁定，必须先处理当前事件。

## 存档与重放

V1 使用 Seeded RNG，核心规则禁止 `Math.random()`。成功操作会记录玩家行动、时间前后、事件前后、RNG 状态前后和 GameState 摘要；同一 `runSeed + 同一串操作` 可以重新走规则引擎得到同一最终结果，用于复现 Bug。

本地存档键：

```text
restarting-life:v1
```

整个 `PersistentGame` 在一次完整操作结束后再整体写入。

## 本地运行

环境要求：Node.js >= 20.19，npm。

```bash
npm install
npm run dev
```

Vite 启动后打开终端显示的 `Local` 地址，通常是 `http://localhost:5173/`。

## 自动验收

每次 push / pull request 自动运行：

```bash
npm install
npm run typecheck
npm test
npm run build
```

Stage 7 额外锁定：新一世从 16 岁开始；新一世和成功操作能保存完整快照；UI 年龄、境界、势力和寿元只从 `GameState` 推导；Stage 0～6 的所有回归测试不得退化。

## V1 明确不做

大模型 API、自由文本行动、NPC 自由聊天、回合制战斗、装备 / 法宝系统、复杂炼丹炼器阵法符箓、多宗门、元婴及以上、后端和云数据库。
